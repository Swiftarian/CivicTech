## Reporting a Vulnerability

We take the security of our systems seriously. If you believe you have found a security vulnerability in any of the CivicTech projects (fire_dept_automation or fire_volunteer_management), please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

Please send a detailed report via email to the project maintainers at aliens.01-mettle@icloud.com or open a strictly confidential issue if a private channel is available.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

### Response Timeline

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for addressing the issue.
